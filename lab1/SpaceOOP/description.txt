Предметная область: Космос.

Программа представляет собой консольное приложение для моделирования
объектов Солнечной системы.

Основными объектами предметной области являются космические тела:
звёзды, планеты и естественные спутники.

Базовым классом является абстрактный класс CelestialBody.
От него наследуются классы Star, Planet и Satellite.

CelestialBody содержит общие характеристики космических объектов:
название, массу и радиус.

Класс Star дополнительно содержит температуру и спектральный класс.

Класс Planet содержит расстояние от звезды, период обращения
и информацию о наличии атмосферы.

Класс Satellite содержит родительский объект, расстояние до
родительского объекта и период обращения.

Класс StarSystem объединяет космические тела в звёздную систему
и позволяет добавлять, удалять, искать объекты, а также получать
список орбит всех объектов (метод GetOrbits).

Класс Orbit описывает орбитальные характеристики космического объекта.

Класс DistanceCalculator выполняет расчёт расстояния между планетами.

Класс AstronomicalCatalog предоставляет каталог космических объектов
и позволяет выполнять поиск по названию.

Класс SpaceMission моделирует космическую миссию между двумя
космическими объектами.

Интерфейс IOrbitalObject определяет поведение объектов, имеющих
орбитальные характеристики: период обращения и радиус орбиты.

Для демонстрации полиморфизма объекты Star, Planet и Satellite
хранятся в общем списке типа CelestialBody. При вызове метода
ShowInfo() автоматически используется реализация соответствующего
класса.

Инкапсуляция реализована через закрытое поле mass и свойство Mass,
которое контролирует корректность устанавливаемого значения.

Наследование реализовано через иерархию:

CelestialBody
    ├── Star
    ├── Planet
    └── Satellite

Полиморфизм реализован через переопределение метода ShowInfo()
в производных классах.

Логика взаимодействия объектов заключается в том, что StarSystem
объединяет космические тела, AstronomicalCatalog хранит их для поиска,
DistanceCalculator выполняет расчёты между планетами, Orbit описывает
движение объектов, а SpaceMission моделирует перемещение между
космическими объектами.
